# H.A.R.D. Protocol 0.3: current page content contract

Public identity: **H.A.R.D. Protocol 0.3**. Separate state: **Public Preview**. Full name: Human-centered AI Readiness and Decision Protocol. Exact protocol 0.3-preview.2, MCP 0.3.0rc2, Skill/contract 0.3.0-rc.2 belong in technical details.

The page should explain the method before installation: a completed AI-created result can contain decisions the user has not examined. H.A.R.D. starts from those decisions and connects purpose, criteria, alternatives, reasons, tradeoffs, evidence and remaining human judgment. The outcome may preserve the original choice. It must not promise recovery of a model's unrecorded internal reasoning.

## Entry paths

The overview offers a minimum artifact review and the Developer Library. The minimum route accepts specifications, prototypes and code, including a plan with no implementation. Explain that one person can use it without a measured baseline or ROI calculation. Keep the engineering funding path available with its existing QUICK6/FULL gates. Present independent evaluation as optional and subject to metric eligibility.

Use a constructed coding or SaaS case to show the sequence: a report appears complete; inspect a dependency and the choice of synchronous processing; compare current alternatives; establish which reason is documented or new; check timeout/recovery evidence; retain or revise the choice through a human decision. A logo-only example would narrow a cross-domain rationale incorrectly. No example is evidence of improved outcomes.

Keep four evidence levels visible: specified, walkthrough, implemented and runtime tested. A plan-stage review can be useful before runtime exists. It cannot imply runtime certification. Unassessed items remain visible, and a required-stage missing check remains unresolved.

Targeted deepening describes inspecting a weak choice more closely. Do not display a new validated intermediate profile, invent a score or redefine the existing six gates. Fifteen stable engineering criteria remain discoverable in the library.
