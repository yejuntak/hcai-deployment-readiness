# HARD Protocol 0.2: Public Preview release checks

The current distribution is Public Preview. Public version 0.2 is not a finalized-release or empirical-validation claim. Exact protocol 0.2-preview.1, MCP 0.2.0rc7 and Skill/contract 0.2.0-rc.7 identify this compatibility set.

1. Freeze published predecessor artifacts and verify their hashes.
2. Check common identity metadata, current protocol copies, generated guides, schemas and examples.
3. Run all regressions, real MCP transport and isolated Skill/installed-package checks.
4. Render and inspect the four PDFs; verify preview links, downloads and historical files.
5. Check actual external end-user/advisor use, permission and feedback before considering a finalized release. Synthetic records, correspondence and invitations do not qualify.
6. Keep REMAIN_CANDIDATE in the existing release-check API while prerequisites are unmet. Present that state as Public Preview to readers. There is no automatic promotion.
7. Before website promotion, check for concurrent live changes, pin the verified revision and retain rollback. Recheck the public domain afterward.

The actual-use registry is currently empty. Passing software tests do not establish empirical effectiveness. The rc.3 DOI identifies only that historical release. The older rc.4 checklist remains historical, not the instruction to relabel current records.
