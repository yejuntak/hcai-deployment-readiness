FICTIONAL ARTIFACT / SR-01 / SPECIFICATION WALKTHROUGH

Service request

This is the frozen specification to evaluate. It is not an implemented product. Controls below are described behavior, not live submissions.

1. Request details

Choose General support or Access change. Enter description and requester email. The return control is labeled Go; returning and reopening preserves all entered details.

2. Validation

An empty required field is identified and shows Something is wrong. An invalid requester email is identified; correction preserves other inputs.

3. Send or leave

Send sends the request, including an access-change request. The submission token prevents a second request for the same submission. Explanatory text: Protected.

Leave discards an unsent request and returns to the service list.

4. Response

Success displays a unique reference. The heading uses Request SR-0042; the detail uses sr0042 for the same request.

Server rejection shows the rejection reason and a retry control, preserving details and requester identity.
