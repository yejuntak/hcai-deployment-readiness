# Assemble the evaluator packet

Create a separate delivery folder containing only the evaluator-facing brief, frozen artifact, requirements-brief.csv, recovery-brief.csv and Evaluator-Scorecard.pdf. Fill and independently check the acceptance criteria before delivery. Remove the reference-location field from the administrative brief. Do not distribute the entire repository for a blinded study.

Withhold requirements.csv and recovery.csv outcome columns, reference-key.csv, adjudication records, completed examples and workbooks until records are locked. The reference reviewer keeps a separate restricted folder. Log the exact files delivered and disclosure timestamps. A location on a shared drive is not access separation if evaluators can open it.

Worked-Example/Evaluator-Packet is for training only. The public key makes it unsuitable as an unseen benchmark for prior readers. Use new independently checked cases for a study, and record prior exposure.
